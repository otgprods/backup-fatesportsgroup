Outlook on Mac

  1. Click Copy signature above.
  2. In Outlook, open Settings (Outlook menu at the top left), then Signatures.
  3. Click + to add a new signature and name it Fate.
  4. Click into the signature box and paste (Cmd + V).
  5. Under Choose default signature, set Fate for both New messages and Replies/forwards.

Outlook on Windows

  1. Click Copy signature above.
  2. In Outlook, go to File > Options > Mail > Signatures. In the new Outlook, it is Settings (cog icon) > Accounts > Signatures.
  3. Click New, name it Fate, click into the box and paste (Ctrl + V).
  4. Set it as the default for new messages and replies, then Save.

Outlook on the web (outlook.office.com)

  1. Click Copy signature above.
  2. Click the cog icon at the top right > Accounts > Signatures.
  3. Create a new signature named Fate, paste into the box, set it as the default for new messages and replies, then Save.

Apple Mail on Mac

  1. Open this page in Safari and click the Copy signature button at the top of this page (not the code button further down).
  2. In Mail, go to Mail > Settings > Signatures and click your Fate email account.
  3. Click + and name it Fate. Untick Always match my default message font (this stops the layout being squashed).
  4. Click into the box, delete anything in it, and paste (Cmd + V).
  5. Set Choose Signature to Fate, close Settings and send yourself a test email.
